Concept 1 What it is

Learn X → Y from the right answers

▶ Watch 00:17

Core idea

The algorithm sees pairs of input x and the correct label y. Eventually it takes x alone and gives a reasonably accurate guess of y.

Why it matters

Ng estimates ~99% of the economic value created by machine learning today comes from this one type.

Common confusion

"Supervised" doesn't mean a person watches training. It means the data contains the right answers: the labels.

Concept 2 Applications

Same pattern, different X and Y

▶ Watch 01:03

Core idea

Very different products are the same supervised learning recipe: choose an input X, choose an output Y, learn the mapping.

Lecturer's examples

Spam filtering, speech recognition, machine translation, online ads ("probably the most lucrative"), self-driving cars, and visual inspection in manufacturing (Ng's work at Landing AI).

Spot the pattern

For any ML product, ask: what is x, and what is y?

Concept 3 How it works

Train on pairs, then predict

▶ Watch 03:15

Core idea

First train the model on examples of inputs x with their labels y. Then give it a brand-new x it has never seen and it produces its best guess of y.

In Ng's words

"Take a brand new input X, something it's never seen before, and try to produce the appropriate corresponding output y."

Notice

Labels are needed for training, not for prediction.

Concept 4 Worked example

Predicting house prices

▶ Watch 03:44

Core idea

Plot house size (x) against price (y), fit a model to the data, then read a prediction off the model for any new house.

Lecturer's example

A friend asks about their 750 ft² house. Reading off a straight line fitted to the data, it could sell for about $150,000.

Why it's supervised

Every house on the plot comes with its right answer, the actual price y. The algorithm's job is to produce more right answers.

Concept 5 Model choice

Line or curve? The answer changes

▶ Watch 04:39

Core idea

A straight line isn't the only option. A slightly more complex curve may fit better, and it gives a different prediction from the same data.

Lecturer's example

With a curve, the friend's 750 ft² house comes out closer to $200,000 instead of $150,000.

Don't cherry-pick

It wouldn't be right to pick whichever model gives your friend the best price. Later in the course you learn to choose the model systematically.

Concept 6 Terminology

Regression: predict a number

▶ Watch 06:06

Core idea

House-price prediction is a type of supervised learning called regression: predicting a number from infinitely many possible numbers.

Lecturer's example

The price could be $150,000, $70,000, $183,000, "or any other number in between".

Recap Takeaways

What to remember

  1. Supervised learning learns X → Y from examples with the right answers (labels).
  2. It powers spam filters, speech recognition, translation, ads, self-driving and visual inspection.
  3. Train on (x, y) pairs, then predict y for a brand-new x.
  4. The model you fit (line vs curve) changes the prediction, so choose it systematically.
  5. Regression predicts a number from infinitely many possibilities.
